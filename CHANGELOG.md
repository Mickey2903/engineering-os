# Changelog

All notable changes to this project will be documented in this file.

## [0.3.0] - Unreleased

### Added

- Modular Engineering Core.
- Initial Vault scanner.
- YAML and link metadata parser.
- In-memory Engineering Database.
- Repository abstraction layer.
- Relationship graph.
- Traceability analysis.
- Impact analysis.
- Engineering Health Check.
- Markdown report generation.
- Obsidian command integration.
- Ribbon shortcut.
- Typed EventBus.
- Automated verification script (`scripts/verify.sh`).
- GitHub Actions continuous integration.
- Comprehensive unit test suite.
- Initial project documentation.

### Changed

- Refactored plugin architecture to improve separation of concerns.
- Improved rendering and report generation.
- Simplified health check execution flow.
